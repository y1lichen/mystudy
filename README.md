# model input
- T_dry 室外乾球溫度
- T_wet 室外濕球溫度：濕球溫度代表空氣的「濕度與溫度的綜合體」。它是冷卻水塔靠蒸發散熱的「絕對物理極限」。水塔的水溫永遠不可能降得比室外濕球溫度還低。若是溼度高，今天冷卻水塔效率很差，不能把冷卻水溫度設得太低，不然風扇狂轉也達不到，只會白白浪費電。
- Q_load 建築冷負載：整棟建築當下正在產生的熱量總和。必須保證算出來的供冷能力絕對大於等於 Q_load
- T_sec_return 二次側回水溫：冰水去大樓繞了一圈，吸收熱量後流回機房的溫度。用它來計算自己給出的冰水設定點到底能帶走多少熱量。如果回水很熱，代表大樓很熱，AI 就得考慮把出水溫度調低。
- V_sec_flow 二次側流量：當下有多少加侖的冰水正在流向大樓。流量的 3 次方與水泵耗電成正比
- DP_sec 二次側壓差：大樓末端管路的壓力差。當很多辦公室覺得熱、打開空調閥門時，管路阻力變小，壓差會往下掉。這時會加速水泵來維持壓差。
- CHL_STA_1, CHL_STA_2, CHL_STA_3 (冰水機啟動狀態，0 或 1)
# model outpt
- T_chw_set 冰水供水設定溫度：冰水機把水降溫到這個溫度，然後送去大樓。如果設得很低，大樓會涼得很快，水泵就可以打少一點水。但壓縮機為了製造這麼冰的水會更加耗電。
- T_cdw_set 冷卻水供水設定溫度：冷卻水塔把吸滿廢熱的水散熱到這個溫度，再送回給冰水機。設得很低（接近外氣濕球溫度），冰水機散熱極佳，省壓縮機電；但水塔風扇必須全速狂轉來吹風。
- COMP_1, COMP_2, COMP_3 (冰水機壓縮機轉速)
- CT_FAN_1, CT_FAN_2, CT_FAN_3 (冷卻塔風扇轉速)
- twv_ctrl 三通閥開度：這是一顆安裝在冷卻水管路上的分流閥門。它的作用是決定「有多少熱水要 bypass 冷卻水塔，直接流回冰水機。因為如果冬天或寒流來襲，室外氣溫極低，冷卻水去水塔繞一圈可能會變得太冷了。
